Al-Haimouni Design System

Tokens, layout rules and components used by the portfolio. Link design-system.css from any new page (profile, case study, blog) and you inherit the whole look.

1 · Colour

Each discipline owns one accent. Set data-theme="service|electrical|software|management" on <body> (or any wrapper) and every component re-colours through --accent. Pages without a theme use --accent: var(--c-brand) (royal blue).

4 · Layout — 12-column grid · 1200px container · fluid gutter · breakpoints 640 / 960

Use .container for page width, .section for vertical rhythm (112px), .section-head for eyebrow + heading + lead, and .grid for a 12-column grid. Card grids: 3 columns ≥ 960px, 2 columns ≥ 640px, 1 column below.

5 · Shape, depth & motion

CARD

radius 22px · hover lifts 6px + accent glow

Radii --r-sm 8 · --r-md 14 · --r-lg 22 · --r-pill. Easing cubic-bezier(.2,.7,.2,1); durations .18s / .45s / .9s. Reveal-on-scroll via .reveal + adding .in with IntersectionObserver. Scroll-linked effects use a per-section CSS variable --p (0→1). Always honour prefers-reduced-motion.
